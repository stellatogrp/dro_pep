# K=50 certification campaign: reproducible pipeline

End-to-end recipe from configs to figures for the K=50 / N=100 runs of the
three certification experiments (LogReg on a9a, Quad mu=0, Lasso).

## 1. Configuration (committed)

- `src/configs/{logreg,quad,lasso}.yaml`: `K_max: 50`,
  `training.expectation_N = training.cvar_N = 100`.
- LogReg eps grid: logspace 1e-5..10^-0.5, 13 points. Quad mu=0 runs
  override to logspace 1e-1..10, 13 points. Lasso: linspace 1e-3..1e-1,
  7 points.
- Family constants (L, R, lambda) are computed at runtime from fixed seeds
  in the configs; nothing is hand-entered.

## 2. Cluster runs

On the cluster clone (`git pull` first):

- samples/pep stages: `sbatch --array=... slurm_scripts/run_{logreg,quad,lasso}_cert_{samples,pep}.sh`
  (array index = algorithm; see the `*_params` tables in `run_*_experiment.py`).
- DRO stage: chunked per K-range via `slurm_scripts/run_logreg_cert_dro_chunk.sh`
  (logreg) and `slurm_scripts/run_cert_dro_chunk.sh` (quad/lasso).
  The complete list of chunk jobs -- K ranges, eps/alpha trims, memory,
  time limits -- is generated by the campaign manifest:

      python slurm_scripts/k50_campaign.py audit             # completeness report
      python slurm_scripts/k50_campaign.py submit --dry-run  # inspect
      python slurm_scripts/k50_campaign.py submit            # submit whatever is incomplete

  `submit` is idempotent: it only submits units whose chunk output is
  missing or short of the expected (eps x alpha) row count for some K.
  Do not audit/submit while jobs are still running.
  Never pass `-q` to sbatch (it is --qos and swallows the next flag).

## 3. Collect

Locally, from `src/experiment_plots/`:

    python collect_results.py --pull --merge

`--pull` copies all result CSVs from the cluster into `_mirror/`
(gitignored); `--merge` builds each experiment's `data/` layout:
per-(algorithm, measure) `dro.csv` files concatenated from the chunk
outputs, deduplicated on (K, eps, alpha) with later files superseding
earlier partial ones, plus the newest samples/pep outputs per array task.

## 4. Figures

    cd LogReg && python plot_bounds.py    # logreg_obj_val.pdf + CSV, eps sweep
    cd Quad   && python plot_bounds.py
    cd Lasso  && python plot_bounds.py

The cross-validated Wasserstein radius is selected per K inside
`plot_bounds.py` (95% coverage across the 100 sampling repeats in
`sample_summary_dist.csv`); the chosen eps values are printed to stdout.
